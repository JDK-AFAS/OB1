# raw/

**Your input dump. Don't organise — just drop.**

Dump anything here:

- Meeting notes
- Articles, links, highlights
- Tasks and to-dos
- SOPs and procedures
- Transcriptions
- Diagrams, screenshots (link or describe)
- Any raw thought or reference

Claude reads this folder and processes it into `wiki/` and `outputs/`. You never need to tidy it yourself.
