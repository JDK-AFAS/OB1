# wiki/

**Claude's territory. Organised, standalone knowledge docs.**

This folder is maintained by Claude. Each file is a self-contained topic page distilled from `raw/`:

- One topic per file, named clearly (e.g. `supabase-edge-functions.md`)
- Written to be reusable and referenceable
- Updated whenever new raw material comes in that relates to the topic

Do not dump raw notes here — that's what `raw/` is for.
